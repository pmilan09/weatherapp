# Weather App

Magyar nyelvű időjárás-alkalmazás Open-Meteo adatokkal.

## Indítás
Nyisd meg az `index.html` fájlt böngészőben. Internetkapcsolat szükséges.

## Fájlok
- `index.html` – alkalmazás és API-hívások
- `style.css` – eredeti megjelenés és néhány kiegészítő stílus
- `activities.js` – időjárási aktivitás-becslések

A saját helyzet funkcióhoz a böngésző helymeghatározási engedélye szükséges. Az aktivitási ajánlások tájékoztató jellegűek.
